## 一、深挖结论（方法论）

### 1. 去水方法：Shin = 乘法归一化，幂法更差
- 185 场结算样本实测：**乘法归一化 Brier 0.6351 = Shin 0.6351 < 幂法 0.6410**
- 竞彩 1X2 的 Shin 参数 z→0（无内幕交易偏斜），退化为乘法归一化
- 幂法 k>1 会把热门概率抬高/冷门压低（假设"无热门-冷门偏差"），但竞彩 1X2 实际
  不存在该偏差，反而更差
- **结论：维持 Shin 去水即可，无需改。**

### 2. 水位（赔率变动）信号方向反了（真 bug）
- fetch 口径：`compression = 初盘/即时盘`，>1 = 赔率下降 = 资金涌入
- main.py 却写成"<0.95 = 下降"，符号反转 → 盘口信号被反向应用
- 已修复：>1.05 加仓、<0.95 减仓（与 fetch 口径对齐）

### 3. 让球（亚洲盘）是独立预测，但不能对抗市场
- 让球方向与胜平负方向可以不同（本来就是独立玩法），保留
- 但让球 EV 之前用纯模型比分矩阵（Brier 弱于随机），回测 83 场 ROI -18.1%
- 已改：让球概率 = (1-w)×模型 + w×市场去水，w=0.882（与 1X2 融合同口径）
  + 方向一致性闸（模型让球方向必须与市场同向才推荐）

# 二、比分校准 + 多玩法 EV + 冠军显著性（2026-08-14 第二批）

## 5. 比分/总进球校准（新增 engine/learning/score_calibration.py）

**证据**：810 场全量赛果经验分布——
- 总进球：0球 6.7% / 1球 21% / 2球 22.3% / 3球 22.1% / 4球 15.4% / 5球 6.5% / 6球 3.8% / 7球 1.5%（≤2球 50% / ≥3球 50%）
- 比分：1-0 13.2% / 2-1 10.2% / 1-1 10.1% / 0-1 7.8% / 2-0 6.8% / 0-0 6.7% / 1-2 5.9% / 0-2 5.4% / 2-2 5.4%...

模型比分矩阵系统性偏向低比分（top1 为 ≥3球 31% vs 实际 50%），且 3+ 球被低估
（模型 3球 17% vs 实际 22%、4球 10% vs 15%）。

**做法**：贝叶斯收缩 `calibrated = (1-shrink)×模型 + shrink×经验先验`，shrink=0.5。
先验由 results.json 全量赛果重建（build_site 结算后，滞后一天无泄漏）。
- 实测：3+球占比 32.3% → 40.2%（向经验 50% 靠拢）
- 波胆单腿命中率从"全局 12.2%"升级为"该具体比分经验频率"（1-0 13.2% / 0-0 6.7%）

**接入**：multi_play_ev（总进球/波胆 EV）+ score_parlay（比分串单腿）。

## 6. 波胆/总进球 EV 恢复（f 键修复的延续）
- f 键解析修复后，8/14 首次能评估 51 个玩法（17 场 × ttg/crs/hafu）
- 总进球 3 个推荐、波胆 0 个推荐（波胆 32% 抽水难破，符合预期）
- 这是模型"有独有价值"的方向：xG 驱动的总进球分布 vs 抽水 20% 的 ttg 市场

## 7. 冠军选择显著性（fusion_optimizer）
- 问题：val_matches=20（SE≈0.015）+ 晋升阈值 0.002-0.005 → 噪声判定，
  157 次决策 126 hold/16 promote 与随机游走无法区分
- 修复：`val_matches 20→80` + `min_z=1.96`，晋升要求
  `improvement ≥ max(0.002, 1.96×SE)`（配对显著性）
- 实测：当前冠军(0.10/0.75/0.15) vs 纯市场(0.05/0.85/0.10) improvement=-0.0003、
  SE=0.0012、阈值 0.0024 → 不显著，hold（正确，避免噪声晋升）

# 三、shrink 离线回测 + 半全场深挖（2026-08-14 第三批）

## 8. 比分校准 shrink 离线回测（不拍脑袋 0.5）
- 151 场有 top_scores + 赛果，时间切分（08-08 前建先验 103 场，之后评估 48 场）
- 结论：**shrink=0.4 最优**（logloss 4.4101），0.3-0.5 曲线平坦
- 关键发现：模型比分**排序有真信息**——shrink=0（纯模型）top1 命中 27.1%，
  远高于经验 top1（1-0 仅 13.2%）；但**概率幅度过度自信**，需向先验轻微收缩
- 已把默认 shrink 0.5 → **0.4**

## 9. 半全场（hafu）深挖：htft 是硬编码启发式，需市场主导
- htft 模型用硬编码动量参数（MOMENTUM_LEAD=0.12 等），概率常与市场严重背离
  （edge +35%~+220%，全被 >30% 闸拦下，融合前 0 推荐）
- 且 htft 全场边际与 1X2 不一致（周五001：htft 主 0.33 vs 市场 0.23）
- 修复：与让球同口径——**市场主导融合（w=0.882）+ 方向一致性闸**
- 融合后：17 场 1 个推荐（周五017 HA，模型与市场同向），2 个"异向"被拦
- 波胆/总进球保留"模型 xG 主导 + 经验校准"（模型有独有价值），半全场/让球
  走"市场主导"（模型是弱启发式）——按信号强弱分权
