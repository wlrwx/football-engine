## 2. 账目核实（这是本轮最有价值的发现）

你问的"34 笔是不是就是入账的全部"——**是的，而且账本身有更大的问题**。

### 2.1 三层漏斗

```
预测 1,017 场  →  计划 403 条  →  入账 34 条
预测→计划   39.63%
计划→入账    8.44%
```

| 桶 | 累计条目 |
|---|---|
| stable | 11 |
| value | 47 |
| lottery | 31 |
| parlay | 119 |
| score_parlay | 195 |
| **合计** | **403** |

**入账只发生在 2026-08-08 ~ 09-14 的 20 天**，之后 27 天
（有预测、有计划）**入账为零**。

34 笔的构成：赢 7 / 亏 27，PnL −1129.2；
赔率档 `1.0-1.5:5, 1.5-2.0:9, 2.0-3.0:18, 3.0+:2`。

### 2.2 虚拟资金曲线：自峰值 −98.9%

```
起始 (2026-07-19)  bankroll    10,000
峰值 (2026-07-27)  bankroll   349,134   ← 8 天涨 35 倍
当前 (2026-10-11)  bankroll     3,871
自峰值回撤  −98.9%      相对起始  −61.3%
```

对照配置：`reference_bankroll: 5000`、`monthly_stop_loss: 5000`。

### 2.3 断路器在暴跌期间一次都没触发

`breaker_multiplier < 1.0` 的天数只有 **3 天**：2026-07-19 / 07-20 / 07-22，
**全部在最开头**。

从峰值 349,134 跌到 3,871 的整个过程里，断路器是关闭的。
这是 `engine/strategy/circuit_breaker.py` 的实际行为，
和它文件名暗示的保护意图不符。

### 2.4 两套记账互不勾稽

| 口径 | 覆盖范围 | 数值 |
|---|---|---|
| A. `ticket_plan.bankroll` | 07-19 .. 10-11（82 天） | 10,000 → 349,134 → 3,871 |
| B. `review_ledger.pnl` | 08-08 .. 09-14（20 天） | 34 笔，−1129.2 |

A 里 −98.9% 的回撤在 B 里完全看不到。两套没有共同的对账口径。

**这和 PR#6 里修的 `ev_report` 口径脱节是同一类问题**：
一个数从 A 里算出来，从 B 里查不到，于是谁都说不清真实结果是多少。

### 2.5 诚实的边界

34 笔在统计上什么都证明不了（7 胜 27 负，p ≈ 0.38，二项检验远不显著）。
但上述三条**都不是统计推断，是记账事实**：漏斗转化率、资金曲线、断路器触发记录。
它们不需要 34 笔样本来成立。

## 3. 下一步实验方案（分支即实验）

你认可"分支就是实验"。那 6.25% 的权重槽，按下面顺序试，
每步都有明确的判定门禁，失败就停：

### E1 · 盘口移动特征（唯一有先验支持的信号）

```
p_final = p_market_devig + λ · f(盘口移动, 跨公司分歧, …)
```

数据已就位：33,060 场同时有开盘和收盘，平均绝对移动 0.01693、最大 0.26805；
62,344 场有跨公司分歧（Max−Avg）。

**判定门禁**：`λ=0` 必须作为候选并入。
- λ 的最优值显著 > 0 → 模型层终于挣到了那个权重
- λ 的最优值 = 0 → 这是一个**完整且可发表的结论**："除市场外无边际信息"

回放框架已建好，跑一次约 15 分钟。

### E2 · 跨盘口一致性

用同一个比分矩阵给 1X2 / 亚盘 / 大小球定价，要求同场多盘口方向一致。
数据：33,060 场有收盘亚盘 + 收盘大小球。

不依赖扩样本，可与 E1 并行。

### E3 · 决策层回放（用 71,774 场）

把你当前的 `min_probability_edge` / Kelly / favorite_band / layer_boost
放到 71,774 场上离线回放。**注意这只能验证已有配置，不能替代 E1**——
用 71,774 场去证明 `min_probability_edge=0.03` 是否合适，
和你现在用 955 场做同样的事，区别只是样本大，不会改变结论的性质。

### 顺序
**E1 → (通过才) E3**，**E2 并行**。不要先做 E3。
