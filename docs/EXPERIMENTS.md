# 实验登记表（EXPERIMENTS）

> 建立于 2026-10-11。**开工前登记，跑完不许改判定标准。**

## 为什么需要这张表

workbuddy 的建议里有一条成立且被低估了：

> 如果 agent-auditor 跑 50 个诊断、agent-X 跑 50 个假设，各取最好的那个报上来，
> 多重比较照样骗过去。

`PROPOSAL.md`（workbuddy 方案）管的是**单次实验**的预注册；
这张表管的是**跨 agent 的组合级**多重比较。两者互补，缺一不可。

同样的道理，qwen 自己给联赛异质性标了 FDR 警告，却没把它用在自己的 agent 组合上。

## 登记规则

1. 任何实验开工前在下面登记一行：假设 / 分支 / 主指标 / 判定日 / 最小样本量
2. **判定标准写死后不许改**。看到 p=0.06 就把阈值改成 0.1 的实验一律作废
3. 组合级结论必须过 BH-FDR（α=0.10），单实验 p 值不能直接当结论
4. 已登记但失败/中止的实验**保留行、标注结果**，不得删除——失败结论和成功结论价值相同
5. `docs/analysis_20261011/` 下的分析文档是对外可审计的推理记录，改结论必须同步更新

## 两个实验合起来的结论（2026-10-11）

| 方向 | 检验对象 | 结果 |
|---|---|---|
| E0 | 球队实力能否优于市场 | **显著更差**（t=+34.74） |
| E1 | 市场修正能否优于市场收盘价 | **与市场无差异**（t=−0.80，不显著） |

两条路撞同一堵墙：**去水收盘价是不可逾越的基准**。

因此 `fusion.model_weight = 0.05`（有效 6.25%）这个权重槽，
**现有数据里没有任何候选能挣到它**。
`λ=0`（纯市场）不是一个失败选项，它有两组独立证据支撑。

注：优化器独立搜出的 `best_weights = {model: 0.0}` 与此一致，
它当时被 REJECT 只因 t=1.64 < min_z=1.96 —— **阈值与可及效应量不匹配**。
