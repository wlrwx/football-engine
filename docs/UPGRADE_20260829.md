## 一、诊断结论

用账本三路概率（model_raw / market_fair / djyy_prob）+ 每日落盘的冻结特征
（sina 水位 / 同赔 / combo）重放融合链：

| 臂 | n | Brier | 命中率 |
|---|---|---|---|

| **纯市场（去水）** | 364 | 0.5834 | 54.7% |

| 回放-纯融合（全关） | 426 | 0.5902 | 53.1% |

关键发现（与 8/14 的结论修正）：

1. **平局工程链不是主凶**。逐项消融显示：league_draw_anchor 全样本关掉反而更差
   （Δ=-0.0033, t=1.9）→ 保留；league_draw_baseline / market_draw_pull 触发极少
   （Δ=0）→ 保留。
2. **真凶在不可回放层：lgbm 掺混 + 新鲜度收缩 + isotonic/温度**，合计 +0.0296 Brier。
   - isotonic+温度 实测只占 +0.004（加载拟合对象回放验证，t=0.7 不显著）
   - 新鲜度触发率高达 43.6%（不是偶发护栏，是高频改写）
   - 【2026-08-29 二轮修正】剩余 ~+0.025 原归因 LGBM 不准确：LGBM 从未
     训练过（无训练调用点，min_train_samples=500 > 账本 426，is_available
     恒 False）→ 残差主体是新鲜度收缩。两者当时均已关闭，行为不受影响
3. 水位信号在概率层 ±0.02 修正有害（关掉 +0.0013/+0.0015 双段一致），
   但作为信号本身极强（market_signal_hit 命中 0.693 vs 未命中 0.423）
   → 迁到投注层做注量闸门。
4. 融合权重网格（train 60% 选优 / val 40% 配对验证）：model→0 方向最优
   （val Δ=+0.0034, t=1.6），champion 更新为 0.05/0.75/0.20。
